# 고객 제안기반 맞춤형 여행패키지 제안 플랫폼
![image](https://github.com/user-attachments/assets/d7ba2d35-eb39-434f-b2ae-85750be5c248)

## 프로젝트 소개

**우끼끼(우리끼리 만드는 패키지여행)** 는 2030 세대를 위한 여행 계획 및 방 찾기 서비스입니다. 최근 변화하는 2030 세대의 소비 트렌드를 반영하여, 여행과 투자에 집중하는 라이프스타일을 지원하는 것을 목표로 합니다.

2030 세대는 최근 몇 년간 여행과 투자에 대한 지출이 증가하고 있으며, 우끼끼는 이러한 트렌드를 반영하여 간편하게 방을 찾고 여행을 계획할 수 있도록 도와줍니다.

## 주요 기능
![image](https://github.com/user-attachments/assets/e56336db-b5c5-4d0e-bb56-5336a7be3ccc)
![image](https://github.com/user-attachments/assets/5475b11b-c0af-4bd0-88ee-d31b453334d1)

- **여행 일정 설정**: 출발일과 돌아오는 날짜를 손쉽게 설정할 수 있습니다.
- **맞춤형 방 검색**: 출발지와 도착지를 설정하여 사용자 맞춤형 방을 찾습니다.
- **패키지 여행 제공**: 다양한 패키지 여행 상품을 탐색하고 선택할 수 있습니다.
- **공동 여행 설계**: 친구들과 실시간 협업을 통한 여행 일정 구성(WebRTC 기반)
- **결제 시스템**: 맞춤 패키지 선택 후 간편 결제 기능 제공

## 주요 타겟층

- 여행과 투자에 관심이 많은 2030 세대
- 간편하게 여행 계획을 세우고 싶은 사용자
- 합리적이고 효율적인 여행을 원하는 사용자
